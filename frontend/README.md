# Frontend Bruno Pizza

Interface React et TypeScript de Bruno Pizza 1.1.0.

La documentation de référence se trouve à la racine du projet :

- [démarrage et commandes](../README.md) ;
- [guide utilisateur](../docs/GUIDE_UTILISATEUR.md) ;
- [architecture technique](../docs/ARCHITECTURE_TECHNIQUE.md).

Le frontend lit les fichiers Excel localement. Il communique avec le backend
uniquement pour le catalogue, les recettes et les photos.
